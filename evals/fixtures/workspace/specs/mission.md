# Mission: Acme Notes

> A small note-taking web app used to try out spec-driven development.

## Problem Statement

Acme Notes grows feature by feature, and each change currently lands without a
written spec. The team wants every behavior recorded before it ships.

## Target Users

| Persona | Goal | Key Workflow |
|---------|------|--------------|
| Maintainer | Add behavior without losing the existing contract | Plan, implement, record |
| Reviewer | See what a change does to existing behavior | Review the plan and the spec delta |

## Core Capabilities

1. **Write notes**: Create, edit, and delete a note
2. **List notes**: Show the notes in most-recently-changed order
3. **Theme the app**: Render the interface in a light or dark theme
